# 読書ノート

ISBNから本の情報を自動入力できる読書記録アプリです。GitHub Pagesで公開し、スマホのホーム画面に追加して使えます。
データと表紙画像は、自分のGoogleドライブ(「読書ノート」フォルダ)に保存されます。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.webmanifest / icon-192.png / icon-512.png | ホーム画面に追加するための設定とアイコン |
| sw.js | 一度開いた画面をオフラインでも表示するための仕組み |

5ファイルとも、同じフォルダ(リポジトリの直下)に置いてください。

## 1. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る(例: `reading-notes`)。**Public**にします(無料プランのPagesは公開リポジトリが前提です)。
2. 5ファイルをアップロードして Commit する。
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
4. 数分後、`https://<GitHubユーザー名>.github.io/reading-notes/` で開けます。

公開されるのはアプリの画面だけです。本のデータはGoogleドライブに入るので、他の人には見えません。

## 2. Googleドライブ連携の準備(最初の1回だけ)

アプリがドライブを使うには、自分用の「クライアントID」が必要です。画面の名前は変わることがあるので、近い項目を探してください。

1. [Google Cloud Console](https://console.cloud.google.com/) にGoogleアカウントでログインし、新しいプロジェクトを作る(名前は自由)。
2. **APIとサービス → ライブラリ** で「Google Drive API」を検索して **有効にする**。
3. **Google Auth Platform(OAuth同意画面)** を設定する。
   - ユーザーの種類: **外部**
   - アプリ名: 読書ノート / サポートメール: 自分のGmail
   - **テストユーザー**に、自分のGmailアドレスを追加する。
4. **クライアント → クライアントを作成** を選び、種類は **ウェブアプリケーション**。
   - **承認済みのJavaScript生成元**に `https://<GitHubユーザー名>.github.io` を追加する(`/reading-notes` などのパスは付けません)。
5. できあがった **クライアントID**(`〜.apps.googleusercontent.com`)をコピーする。

## 3. アプリで接続する

1. 公開したURLを開き、右上の **⚙** を押す。
2. クライアントIDを貼り付けて **「Googleドライブに接続」** を押す。
3. Googleのサインイン画面が出ます。「このアプリは確認されていません」と出たら、**詳細 → (アプリ名)に移動** で進みます(自分で作ったアプリなので問題ありません)。
4. 「ドライブのファイルを表示、編集、作成、削除」の許可が出ます。これはこのアプリが作ったファイルだけが対象で、ほかのファイルには触れません。
5. ドライブに「読書ノート」フォルダができ、`books.json`(データ)と表紙画像が入ります。

スマホでも同じ手順で、クライアントIDを貼って接続します。以降は、PCとスマホで同じデータが見えます。

## 4. スマホのホーム画面に追加する

- **iPhone(Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android(Chrome)**: メニュー → 「ホーム画面に追加」または「アプリをインストール」

## 使い方のメモ

- 追加・編集・削除すると、数秒後に自動でドライブへ同期されます。アプリを開き直したときも同期します。
- 同じ本を2台で別々に編集した場合は、あとで保存したほうが残ります(本ごとの判定です)。
- 認証は約1時間で切れます。「☁ 要再接続」と出たら、⚙ → 「今すぐ同期」を押してください。
- 表紙画像は、画像を選んだ場合はドライブに保存されます。ISBN検索で入った表紙は、取得できた場合にドライブにも控えを保存します。一覧の表示にはURL、または端末内の小さな画像を使います。
- ドライブ側で`books.json`や画像を消したり名前を変えたりすると、同期が正しく動かなくなることがあります。
- 削除した本の画像は、ドライブに残ります(必要なら手動で消してください)。

## 以前のデータを引き継ぐ

以前のバージョンで登録した本は、旧版で「書き出し」したJSONを、新しい版の **⚙ → 読み込み** で取り込めます。

## 既知の注意点

- iPhoneでホーム画面から開くと、Safariとは別の保存領域になります。ホーム画面のアプリ側でも、もう一度⚙から接続してください。サインイン画面が出ない場合は、Safariで開いて使ってください。
- ISBN検索は、openBDとGoogle Booksの無料の公開APIを使っています。イラストレーターやあらすじが取れない本もあります。
