Librino

プライバシーポリシー

制定日: 2026年10月16日

「Librino 読書ノート」(以下「本アプリ」)は、個人(hachi922)が運営する、読んだ本の記録を残すための無料のWebアプリです。本アプリにおける情報の取り扱いを、次のとおり定めます。

1. 本アプリが扱う情報

  • 利用者が本アプリに入力した読書記録(題名、著者、タグ、評価、感想、日付、表紙画像など)
  • Googleドライブに接続した場合に限り、そのドライブ内の、本アプリが作成したファイル

本アプリに専用のサーバーはありません。入力された情報が、運営者のサーバーに送信・保存されることはありません。運営者が、利用者の読書記録やGoogleアカウントの情報を見ることもできません。

2. 情報の保存場所

  • 端末のブラウザ内: 読書記録は、お使いの端末のブラウザ(localStorage)に保存されます。
  • 利用者自身のGoogleドライブ: 利用者がGoogleドライブへの接続を選んだ場合、「読書ノート」というフォルダに、データ(books.json)と表紙画像が保存されます。これは、複数の端末でデータを同期するためです。

3. Googleユーザーデータの利用

  • 本アプリは、Googleドライブの権限として「drive.file」(本アプリが作成したファイルの表示・編集・作成)のみを要求します。利用者のドライブにあるそれ以外のファイルには、アクセスしません。
  • この権限で取得した情報は、読書記録の保存・読み込み・端末間の同期という、本アプリの機能を提供するためだけに使用します。
  • これらの情報を、運営者や第三者に提供・販売したり、広告に使用したり、人が閲覧したりすることはありません。
  • 本アプリによるGoogle APIから得た情報の使用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に準拠します。
  • Googleのアクセストークンは、同期のために、約1時間の間のみブラウザに一時的に保存されます。

4. 外部サービスの利用

本アプリは、次の外部サービスを利用します。

  • openBD / Google Books API: 本の情報(題名、著者、あらすじ、表紙など)を取得するため、利用者が入力したISBNまたは検索語が送信されます。
  • Google Identity Services: Googleアカウントでの認証のために利用します。
  • Google Fonts: 画面のロゴの文字を表示するために利用します。
  • GitHub Pages: 本アプリの配信に利用します。

これらのサービスにおける情報の取り扱いは、各サービスのプライバシーポリシーに従います。

5. Cookie・アクセス解析・広告

本アプリは、アクセス解析ツールや広告を使用していません。

6. 情報の削除と連携の解除

  • アプリの「⚙ → 接続を解除」で、Googleドライブとの連携を解除できます。
  • Googleアカウントのアカウントの権限の管理ページから、本アプリへのアクセス許可を取り消せます。
  • ドライブの「読書ノート」フォルダを削除すると、保存されたデータがなくなります。
  • 端末内のデータは、ブラウザのサイトデータを削除すると消えます。

7. 変更について

必要に応じて、本ポリシーを変更することがあります。変更後の内容は、このページに掲載します。

8. お問い合わせ

本アプリに関するお問い合わせは、運営者のGitHub(github.com/hachi922)までお願いします。
